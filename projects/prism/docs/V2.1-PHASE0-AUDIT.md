## 4. What is sound (verified)

- anon: zero table privileges; privileged RPCs denied (live 42501).
- User-facing functions gate on caller JWT + server-side role/ownership:
  manage-users, reclassify-articles, extract-company-profile all 401 on
  anon/bad JWT (live). Company tables owner-RLS; profile loaded through
  caller client in matching.
- risk_scores append-only; V2 stores full inputs snapshot + version.
- SECURITY DEFINER: search_path set; invoker anon-revoked; Vault-held key.
- Secrets: none in Git/frontend (scan clean); AI errors never echo keys.
